# Amina — інтернет-магазин одягу

Сучасний магазин одягу зі стриманим дизайном, адмінкою для повного керування замовленнями та каталогом, чат-ботом і сповіщеннями.

**Стек:** Angular 21 (клієнт) · Node.js 22 + Express (API) · PostgreSQL (Neon) · хостинг Render · CI/CD через GitHub Actions.

## Можливості

**Для покупців**
- Головна з банерами, новинками, обраними речами; каталог з динамічними категоріями й підкатегоріями будь-якої вкладеності
- Фільтри: розмір, колір, ціна, наявність, знижки, новинки; сортування; пошук з миттєвими підказками
- Сторінка товару: галерея, кольори, розміри з наявністю, таблиця розмірів, швидке додавання з картки
- Кошик-шторка, обране, особистий кабінет з історією замовлень
- Оформлення: Нова пошта (відділення/кур'єр, автопідказки міст і відділень), Укрпошта, самовивіз; оплата через **QR Monobank (банка)**, картою онлайн (еквайринг monobank), IBAN або накладений платіж; промокоди
- Сторінка замовлення зі статусом, QR-кодом для оплати та підпискою на оновлення в Telegram/Viber
- Чат-бот «Аміна»: підбирає товари, відповідає про доставку/оплату/розміри, перевіряє статус замовлення, передає розмову менеджеру

**Адмінка (`/admin`)**
- Огляд: виручка, замовлення, середній чек, графік, топ-товари, залишки, що закінчуються
- Замовлення: фільтри, пошук, зміна статусу/оплати, ТТН, редагування складу, знижки й доставки, внутрішні нотатки, історія змін, журнал сповіщень, повідомлення клієнту, друк, експорт у CSV
- Товари (варіанти розмір × колір, залишки, фото з перетягуванням), категорії (дерево з drag&drop), клієнти, промокоди, банери, FAQ (його ж використовує чат-бот), способи доставки й оплати, налаштування магазину/оплати/сповіщень/чат-бота, адміністратори

**Сповіщення про замовлення**: email клієнту й адміну, Telegram (адміну — нові замовлення; клієнту — зміни статусу після підписки), Viber, WhatsApp (Cloud API, опційно). Кожен канал вмикається змінною середовища — без неї просто не використовується.

## Розгортання (Neon + Render + автодеплой)

1. **База Neon** — створіть проєкт на [neon.tech](https://neon.tech), скопіюйте connection string (`postgresql://...?sslmode=require`).
2. **Render** — New → Blueprint → оберіть цей репозиторій (використовується `render.yaml`). Заповніть змінні:
   - `DATABASE_URL` — рядок з Neon
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD` — перший адміністратор (створюється при першому запуску)
   - `PUBLIC_URL` — адреса сайту, напр. `https://amina.onrender.com`
   - решта — за потреби (див. `.env.example`)
   Міграції БД виконуються автоматично при кожному старті.
3. **Deploy Hook** — Render → сервіс → Settings → Deploy Hook → скопіюйте URL.
4. **GitHub** → Settings → Secrets and variables → Actions:
   - секрет `RENDER_DEPLOY_HOOK_URL` — URL з кроку 3
   - змінна `PUBLIC_URL` (опційно) — щоб workflow дочекався, поки сайт підніметься
5. Гілка за замовчуванням — `main`. Кожен **merge pull request у `main`** запускає `.github/workflows/ci-deploy.yml`: збірка → smoke-тест з реальною PostgreSQL → деплой на Render. Для PR запускається тільки перевірка.

> Безкоштовний Render «засинає» після 15 хв без відвідувачів — перше відкриття може тривати до хвилини.
> Фото товарів зберігаються в базі (стискаються у WebP), тож не зникають після перезапуску Render.

## Інтеграції

| Що | Змінні | Як отримати |
|---|---|---|
| Email | `RESEND_API_KEY`, `MAIL_FROM` | [resend.com](https://resend.com), підтвердіть домен. (На безкоштовному Render SMTP заблоковано, тому Resend.) |
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`, `TELEGRAM_WEBHOOK_SECRET` | @BotFather → новий бот. Напишіть боту `/id` і додайте отриманий chat ID в адмінці → Налаштування → Сповіщення |
| Viber | `VIBER_BOT_TOKEN`, `VIBER_BOT_URI` | [partners.viber.com](https://partners.viber.com). Для свого ID напишіть боту `/id` |
| WhatsApp | `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_TEMPLATE` | Meta WhatsApp Cloud API, затверджений шаблон з 4 параметрами |
| QR Monobank | — | Адмінка → Налаштування → Оплата: посилання на банку `https://send.monobank.ua/jar/...` |
| Оплата карткою | `MONOBANK_TOKEN` | [api.monobank.ua](https://api.monobank.ua) → еквайринг |
| Нова пошта | `NOVA_POSHTA_API_KEY` | Кабінет НП → Налаштування → Безпека → API-ключ |
| Чат-бот (AI) | `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com). Без ключа бот працює у простому режимі (FAQ + пошук товарів) |

## Локальна розробка

```bash
cp .env.example .env               # вкажіть локальну БД
npm run install:all
npm run dev:server                 # API на :3000 (міграції + демо-дані автоматично)
npm run dev:client                 # Angular на :4200, /api проксіюється на :3000
```

Адмінка: http://localhost:4200/admin (логін з `ADMIN_EMAIL` / `ADMIN_PASSWORD`).

## Структура

```
server/   API (Express + pg): routes/, services/ (сповіщення, monobank, нова пошта, чат-бот), migrations/*.sql
client/   Angular: app/shop (вітрина), app/admin (адмінка), app/core (сервіси), app/shared
scripts/  генератор демо-зображень
```
